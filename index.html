RAG Vector DB Benchmark

Systematic head-to-head evaluation of Milvus, Qdrant, and Weaviate for RAG workloads. Uses RecursiveCharacterTextSplitter (chunk size 1000, overlap 200) for consistent chunking across all databases. Measures single-query latency, batch throughput, and concurrent load (up to 8 threads). Reports retrieval quality alongside performance to give a complete picture for production selection.

Thesis — LLM Tool Orchestration for Navigation

MSc thesis: leveraging LLMs to generate executable code that composes vision modules as callable tools for multi-object navigation tasks. The LLM acts as a reasoning engine — given a navigation goal, it writes Python that chains detection, depth, and localization modules to form a plan. Extends the ViperGPT paradigm with prompt engineering, few-shot in-context examples, and a ReAct-style reasoning loop for embodied agents.

LLM Code GenerationTool Orchestration Prompt EngineeringFew-shot Learning ReAct

Sentiment & Topic Analysis of Product Reviews

Built a complete sentiment analysis pipeline on Amazon Electronics reviews (5-core dataset). Fine-tuned BERT and RoBERTa-based transformer models using stratified splitting and focal loss to handle severe class imbalance. Applied LDA, NMF, and BERTopic to uncover latent semantic themes and linked them to sentiment patterns for richer product insight.

TransformersBERT BERTopicLDA NMFFocal Loss

Vision Transformers & Object Detection

Comparative study of CNN and transformer-based object detectors on PASCAL VOC. Fine-tuned Vision Transformer (ViT) models for supervised detection and evaluated RF-DETR — chosen for its deformable attention and fast convergence. Assessed zero-shot generalization with OWL-ViT2, highlighting trade-offs between supervised accuracy and open-vocabulary flexibility across architectures.

Vision TransformersRF-DETR OWL-ViT2PASCAL VOC Fine-tuning

LLM Pruning + LoRA Fine-Tuning

Applied SparseGPT pruning to compress large language models — significantly reducing parameter count and compute cost while preserving near-baseline perplexity. Then used LoRA (Low-Rank Adaptation) to adapt the pruned model for downstream text summarization, achieving strong task performance with a fraction of trainable parameters.

SparseGPTLoRA HuggingFacePyTorch Model Compression

Image Colorization — Conditional GANs

Implemented a conditional GAN framework for automatic image colorization. U-Net generator with a ResNet18 pretrained backbone in the encoder for rich feature extraction, and a PatchGAN discriminator for local realism. Trained on ImageNet samples in Lab color space, predicting ab channels from grayscale L input. Combined GAN adversarial loss with L1 pixel-wise loss to balance realism and color accuracy.
